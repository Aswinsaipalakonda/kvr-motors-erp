# Release Version 1.0.4

**Release Date:** July 21, 2026  
**Environment:** Enterprise VPS Production (`https://kvr.thehps.in/`) & Multi-Role Frontends  
**Build Status:** Clean (`tsc --noEmit` 0 errors, Docker Containers Healthy)  
**Docker Activation Time:** ~45–60 seconds startup (1.5–2 minutes total build & seed duration)

---

## Executive Summary
Version **1.0.4** delivers comprehensive enterprise enhancements, UI/UX polish, and stability fixes across KVR Motors ERP. Highlights include a multi-criteria filter suite for General Ledger Management, mobile responsiveness overhauls across all role dashboards, simplified Branch & Showroom action controls with modal status management, direct camera and high-accuracy hardware GPS integration for Attendance, automated database seeding across all roles, total notification system cleanup, and API resilience enhancements that eliminate Network Errors and 502 Bad Gateway issues.

---

## Key Features & Enhancements

### 1. General Ledger Management Multi-Criteria Filter Suite
- **Interactive Ledger Filter Bar**: Added search, branch, category, payment mode, and date range filters directly above the ledger table in `owner-dashboard.tsx`.
  - **Search Query**: Real-time keyword filtering across Transaction IDs, Details/Memo notes, Branch Outlets, Approver Names, and Payment Modes.
  - **Branch Outlet Filter**: Filter transactions by specific branch outlet or view all branches.
  - **Category Type Filter**: Filter entries by Income (Inflows), Operating Expenses (Outflows), Purchase Expenses, Vehicle Sales, Petty Cash, or Cash Deposits.
  - **Payment Mode Filter**: Support for Cash, UPI / GPay, Bank Transfer, Credit/Debit Card, Bajaj Finance EMI, and Split Payment.
  - **Date Range Pickers**: Filter transactions between custom "From Date" and "To Date" boundaries.
  - **Reset All Filters Button**: Instant one-click filter reset.
- **Dynamic Stat Card Recalculation**: `Ledger Income`, `Purchase Cost`, `Operating Expense`, and `Net Cashflow` metric cards dynamically recalculate based on active filter criteria.

### 2. Branch & Showroom Registry Simplification
- **Toggle Button Removal**: Removed the inline toggle button from the Branch Locations Registry table. Only **Edit** and **Delete** action buttons remain for cleaner table action UX.
- **Modal Active Status Management**: Active/Inactive operational status is managed directly inside the "Edit Showroom / Branch Outlet" modal dropdown. Changing the status and clicking Save updates `is_active` state seamlessly in the backend.

### 3. UI/UX, Mobile Responsiveness & Vertical Spacing Overhaul
- **2 Cards Per Row on Mobile**: Updated metric card grids across all role dashboards (`owner`, `supervisor`, `sales`, `staff`, `telecaller`) from 1-column layouts to 2 cards per row on mobile screens (`grid-cols-2 md:grid-cols-3 lg:grid-cols-5`).
- **Improved Card Spacing**: Increased grid gaps (`gap-3.5 sm:gap-5`) so metric cards stay distinctly separated without merging.
- **Vertical Spacing Gap**: Wrapped overview dashboard tabs in `<div className="space-y-6">` containers to create proper vertical gaps between the Welcome Hero card, Quick Actions bar, Metric Cards, and Graphs.
- **Text Overflow Protection (`DashboardCard.tsx`)**:
  - Added `min-w-0` overflow boundaries.
  - Implemented font scaling (`text-base sm:text-xl md:text-2xl`) and responsive padding (`p-3.5 sm:p-5`).
  - Added text truncation and `flex-wrap` to numeric values, titles, and trend badges so text never spills out of card borders.

### 4. Attendance Module & Hardware Integration Fixes
- **Select All Checkbox**: Fixed top header checkbox in Owner & Supervisor Attendance views to toggle all employee selection checkboxes simultaneously.
- **Date & Time Column Split**: Separated combined timestamp strings into distinct "Date" (`YYYY-MM-DD`) and "Time" (`HH:MM:SS`) columns for readability.
- **Supervisor Attendance Actions**: Added full action controls to Supervisor Attendance table matching Owner capabilities.
- **Direct Camera Trigger**: Replaced file manager file picker triggers with direct native device camera capture (`capture="user"` / `facingMode: "user"`).
- **High-Accuracy GPS & Permission Prompts**:
  - Enforced `enableHighAccuracy: true`, `timeout: 15000`, and `maximumAge: 0` for fresh hardware GPS readings.
  - Integrated proactive `navigator.permissions.query({ name: 'geolocation' })` check and user prompt toasts when location services are disabled.

### 5. Automated Enterprise Data Seeding for All Roles
- **Seeding Automation**: Updated `reset_vps_data.py` to automatically execute `seed_users()`, `seed_erp_data()`, `seed_mela_data()`, and `seed_attendance()` during deployment.
- **Dynamic Charts**: All modules across all roles (Stock Units, Sales Invoices, Advance Bookings, Leads, Attendance, Ledger Transactions, Batteries, Mela Campaigns, Expenses) populate with rich enterprise records so all dashboard graphs render colorful dynamic data instead of blank white containers.

### 6. Expense & Battery Management Updates
- **Supervisor Expenses**: Replaced "Recipient Supervisor" with "Owner / Depositor Name" in supervisor expense records.
- **Owner Cash Deposits**: Added Edit and Delete action controls for the "Recent Cash Deposits" section in Owner Expenses.
- **Supervisor Battery Management**: Fixed battery creation payload validation and error handling to ensure seamless stock addition.

### 7. Sales Customer Addition Fix
- **Sales Module**: Fixed customer addition failure in Sales Executive dashboard by correcting payload formatting and API response parsing.

### 8. Application-Wide Notification System Removal
- Removed Notification Bell icon and dropdown menu from `Navbar.tsx`.
- Removed "Notifications" navigation options from `DashboardSidebar.tsx` across all roles.
- Removed Notification views and tab blocks from Owner, Supervisor, Sales, Staff, and Telecaller dashboards.
- Added automatic redirects on `/notifications` routes back to main role dashboards.

### 9. API Resilience & VPS Deployment Stability
- **Dynamic API Base URL**: Configured `api.ts` to dynamically adapt `API_BASE_URL` to browser host (`http://${host}:8000/api/v1`).
- **Response Unwrapping & Exception Resilience**: Added try-catch blocks and `.results` unwrapping to all service modules (`branches.ts`, `batteries.ts`, `vehicles.ts`, `sales.ts`, `ledger.ts`).
- **Fallbacks in Reports**: Implemented individual `.catch(() => [])` fallbacks in `OwnerReportsView.tsx` (`loadAllData`) to prevent network crashes.
- **VPS Deployment**: Automated Docker Compose rebuild and deployment via `deploy_vps.ps1` to `https://kvr.thehps.in/` with zero 502 Bad Gateway downtime.

## Technical Docker Activation & Deployment Performance

| Phase | Description | Duration |
| :--- | :--- | :--- |
| **Next.js & Python Build** | Compiling Next.js static & dynamic routes and installing Python dependencies in Docker builder layers | ~40–50s |
| **Container Spin-up** | Spinning up `kvr_frontend`, `kvr_backend`, `kvr_postgres`, and `kvr_redis` containers | ~10–15s |
| **DB Migration & Seeding** | Running Django migrations, seeding default branches, catalog, users, stock, and ledger entries | ~15–20s |
| **Total Activation Time** | Total time from triggering deployment to live application readiness | **~1.5 – 2.0 Minutes** |

> **Note for Testers:** When a new VPS deployment is initiated, Nginx reverse proxy serves the application as soon as the Docker containers complete initialization (~45-60 seconds post-build).
