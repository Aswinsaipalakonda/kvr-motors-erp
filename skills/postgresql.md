# PostgreSQL Skill

## Context
Applies to writing, optimizing, and maintaining PostgreSQL databases.

## Checklist
- [ ] Profile slow queries using `EXPLAIN ANALYZE`.
- [ ] Add indexes for columns frequently used in `WHERE`, `JOIN`, and `ORDER BY`.
- [ ] Secure transactions to prevent race conditions and lock-outs.
- [ ] Write backward-compatible, versioned migrations.
- [ ] Implement database-level constraints for data verification.
