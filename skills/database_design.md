# Database Design Skill

## Context
Applies to database structure planning, tables, and relationships.

## Checklist
- [ ] Normalize relational data to at least 3NF.
- [ ] Define precise data types, foreign keys, and indexes.
- [ ] Add audit columns (`created_at`, `updated_at`, `created_by`, `updated_by`).
- [ ] Map out ER diagrams for complex structural relationships.
- [ ] Enforce cascading rules and null constraint checks.
