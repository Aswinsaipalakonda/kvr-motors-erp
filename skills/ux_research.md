# UX Research Skill

## Context
Applies to user journey design, user flows, and wireframing.

## Checklist
- [ ] Map primary user journeys with clear wireframes.
- [ ] Maintain a 3-click target rule for critical workflows.
- [ ] Design comprehensive states for all forms (loading, error, success).
- [ ] Keep transitions under 300ms to maintain application speed perception.
- [ ] Provide instant visual feedbacks on all pressable actions.
