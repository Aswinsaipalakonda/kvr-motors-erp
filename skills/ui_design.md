# UI Design Skill

## Context
Applies to creating user interfaces for web and mobile.

## Checklist
- [ ] Define cohesive design tokens (colors, spacing, shadows, radius) before styling.
- [ ] Verify harmonic contrast ratio meets WCAG AA standards.
- [ ] Use modern typography pairings (e.g. Inter + Outfit). Avoid browser defaults.
- [ ] Implement smooth CSS/Reanimated transition variables.
- [ ] Avoid generic color palettes; preferTailwind HSL customized classes.
