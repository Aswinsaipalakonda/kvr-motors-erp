# React Development Skill

## Context
Applies to building web applications using React.

## Checklist
- [ ] Write modular, atomic components.
- [ ] Use React Hooks (`useState`, `useEffect`, `useMemo`, `useCallback`) correctly to prevent memory leaks and unnecessary rerenders.
- [ ] Ensure strict TypeScript typings for all props and state variables.
- [ ] Wrap components in React Error Boundaries.
- [ ] Manage local and global states predictably (Context, Zustand, Redux).
