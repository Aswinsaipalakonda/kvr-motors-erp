# Expo Development Skill

## Context
Applies to building, routing, and packaging Expo mobile applications.

## Checklist
- [ ] Use Expo Router for file-system based routing and layouts.
- [ ] Configure `app.json` accurately for plugins, iOS entitlements, and Android permissions.
- [ ] Utilize EAS Build and EAS Update pipelines for deployments.
- [ ] Incorporate Expo native modules using standard Expo APIs.
- [ ] Set up secure stores for credentials using `expo-secure-store`.
