# Documentation Skill

## Context
Applies to documenting codebase conventions, setups, and APIs.

## Checklist
- [ ] Document all public APIs with input/output contracts.
- [ ] Enforce inline docstrings for complex logic statements.
- [ ] Avoid raw absolute file paths; use relative file URLs.
- [ ] Standardize instructions for setup and local deployments.
- [ ] Format markdown files using clean layouts and lists.
