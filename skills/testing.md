# Testing Skill

## Context
Applies to creating, maintaining, and reviewing automated test scripts.

## Checklist
- [ ] Enforce separate testing databases or clean transaction environments.
- [ ] Mock all network requests and external service calls.
- [ ] Assert positive, negative, and edge-case validation inputs.
- [ ] Check code coverage targets for critical business calculations.
- [ ] Implement UI test helpers (e.g. wrapper providers, safe test queries).
