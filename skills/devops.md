# DevOps Skill

## Context
Applies to hosting, infrastructure, containerization, and monitoring.

## Checklist
- [ ] Maintain multi-stage, production-ready Docker configurations.
- [ ] Configure server logs aggregators and monitoring metrics.
- [ ] Enforce automated database backups and recovery plans.
- [ ] Secure communication with SSL/TLS configurations.
- [ ] Utilize caching and CDN layers for static resources.
