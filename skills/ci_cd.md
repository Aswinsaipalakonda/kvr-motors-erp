# CI/CD Skill

## Context
Applies to setting up deployment pipelines and workflows.

## Checklist
- [ ] Configure linting and build validation steps for every pull request.
- [ ] Run unit and integration tests automatically on pipeline runs.
- [ ] Set up staging deployments for verified merges.
- [ ] Enforce status checks (pipelines must pass before code can merge).
- [ ] Optimize cache steps to accelerate pipeline execution speeds.
