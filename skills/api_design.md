# API Design Skill

## Context
Applies to designing REST and GraphQL APIs.

## Checklist
- [ ] Define API contracts (inputs, outputs) before starting implementation.
- [ ] Version APIs from day one (e.g. `/api/v1/`).
- [ ] Use appropriate HTTP status codes (200, 201, 400, 401, 403, 404, 500).
- [ ] Document all endpoints in OpenAPI / Swagger specifications.
- [ ] Enforce consistent JSON response envelopes (e.g. status, message, data).
