# Backend Development Skill

## Context
Applies to backend architecture, logic controllers, and service layers.

## Checklist
- [ ] Implement a clean separation between Controllers, Services, and Repositories.
- [ ] Handle all incoming payloads with strict validation libraries.
- [ ] Enforce strict Role-Based Access Control (RBAC) middleware.
- [ ] Capture and log server exceptions with descriptive error details.
- [ ] Optimize response times by resolving database query bottlenecks.
