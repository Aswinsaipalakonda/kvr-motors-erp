# Mobile Design Skill

## Context
Applies to designing interfaces for iOS and Android mobile platforms.

## Checklist
- [ ] Enforce mobile-first design thinking.
- [ ] Maintain touch target sizes of at least 44x44 dp/px.
- [ ] Handle safe area insets (top status bar, bottom home indicator).
- [ ] Design gestures (swipes, pulls) to match platform standards.
- [ ] Adapt design to prevent keyboard overlapping on input forms.
