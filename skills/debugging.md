# Debugging Skill

## Context
Applies to resolving runtime issues, logic errors, and integration bugs.

## Checklist
- [ ] Reproduce the bug in isolation using a temporary scratch test.
- [ ] Inject clear log outputs along the logical flow to verify state.
- [ ] Use debugger hooks or shell utilities to inspect running variables.
- [ ] Verify environment variables match target setup configurations.
- [ ] Implement the simplest regression fix that addresses the root cause.
