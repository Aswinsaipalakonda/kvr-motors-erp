# Code Review Skill

## Context
Applies to auditing and reviewing code modifications.

## Checklist
- [ ] Ensure all modified lines follow SOLID design principles.
- [ ] Scan for duplicated logic block statements (DRY compliance).
- [ ] Verify TypeScript completeness; check for type casts or `any`.
- [ ] Confirm appropriate test coverage is included with the PR.
- [ ] Verify that error-handling blocks capture actual exceptions.
