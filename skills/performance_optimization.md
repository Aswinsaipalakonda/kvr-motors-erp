# Performance Optimization Skill

## Context
Applies to profiling, rendering optimization, and database tuning.

## Checklist
- [ ] Profile and budget frontend bundle sizes (using bundle analyzer).
- [ ] Minimize image payloads and compress assets.
- [ ] Mitigate redundant API loops and database queries (N+1 query checks).
- [ ] Enable database connection pooling and query result caching.
- [ ] Implement lazy loading/dynamic imports for heavy components.
