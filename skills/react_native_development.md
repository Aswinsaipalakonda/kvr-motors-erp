# React Native Development Skill

## Context
Applies to building cross-platform mobile apps using React Native.

## Checklist
- [ ] Enforce UI consistency using StyleSheet or NativeWind.
- [ ] Optimize flatlist, scrollview, and sectionlist renders (use `keyExtractor`, keep item components simple).
- [ ] Use platform-specific logic (`Platform.OS`, `Platform.select`) only where necessary.
- [ ] Handle hardware back handler actions in Android natively.
- [ ] Profile memory usage and prevent bridge traffic overhead.
