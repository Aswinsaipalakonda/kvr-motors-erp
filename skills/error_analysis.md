# Error Analysis Skill

## Context
Applies to identifying, tracing, and resolving system crashes and exceptions.

## Checklist
- [ ] Parse traceback logs and isolate the source component.
- [ ] Determine the exact state parameters causing the issue.
- [ ] Verify validation constraints on incoming payloads.
- [ ] Identify if the bug is a regression from a previous commit.
- [ ] Test the error pathway explicitly before patching.
