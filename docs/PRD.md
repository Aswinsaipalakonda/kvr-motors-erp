# Product Requirement Document (PRD)

## 1. Goal Description
Provide a brief description of the problem, background context, and what the feature accomplishes.

## 2. User Stories
- **As a** [User Role], **I want to** [Action], **so that** [Benefit].

## 3. Acceptance Criteria
- [ ] Criteria 1: Behavior description
- [ ] Criteria 2: Edge-case behavior description

## 4. Open Questions
Identify any unresolved decisions or ambiguities that need product feedback.
